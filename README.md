# みちくさ Quest — Android α版

[最新版のAPKをダウンロード](https://github.com/yaman7190/michikusa-quest-downloads/releases/latest/download/michikusa-quest-alpha.apk)

このリポジトリはAPKと導入案内の公開配布用です。ダウンロードにGitHubログインは不要です。

アプリを開いて散歩を開始し、記録の通知が出たら画面を消して記録できます。Android 13で健康データを読む場合はHealth Connectの導入と読取許可が必要です。実機の挙動は端末設定により異なります。

過去のdebug署名版から更新する場合、最初の1回はバックアップ後の再インストールが必要なことがあります。α0.10以降は固定署名です。アプリを削除する前に記録を書き出してください。署名のSHA-256指紋・ファイルのSHA-256は各リリースに掲載します。

散歩と健康データは端末内で扱います。地図・標高・地質等の照会では配信元に座標が伝わります。道路検索のサーバー認証はアプリ版では未接続のため、所有者向けWeb版を利用してください。

試験版です。APKには個人のGPS経路・健康記録・運営APIキーは含めていません。広告・決済機能はまだありません。
